Set Mining-Associated Fees

DAO can set deposit fees on Pulse-Ecosystem mining rewards.
Fees are sent to the treasury wallet that is collectively controlled by long term miners and the senate.

Deposit fee is charged once when the user begins mining. Maximum possible deposit fee is 5%.
Mining Fee is charged perpetually(every hour). Maximum possible mining fee is 0.025% hourly
If user has been referred, both the referral and invitee can mint the Referral Bonus (paid from inflation).
