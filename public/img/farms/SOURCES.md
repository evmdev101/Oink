# Farm token artwork

These existing token logos were copied, unchanged, from the official OINK interface's `img` directory in the local audit checkout:

https://github.com/OINK-pls/Piggy-Bank-UI

Local source: `oink-governance-audit-20260907/Piggy-Bank-UI/img`.
`com.png` represents Communitas. HEX T-Share reuses the HEX logo. OINK and Treasury use the site's existing OINK icon outside this folder.

Logos identify assets only; they do not establish token addresses, contract behavior, reward availability, or endorsement. Contract identities remain in the OINK configuration and read-only readers. No DEGEN project files were changed or used for these assets.

PRINT and EARN logos were restored on October 21, 2026 from the same official interface at `https://oink-pls.github.io/Piggy-Bank-UI/img/print.png` and `img/earn.png`.
